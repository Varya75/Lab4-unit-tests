# Лабораторная работа №4. Написание Unit-тестов

## 1. Описание проекта

Проект представляет собой программу на Python для вычисления площади и периметра прямоугольника. В рамках лабораторной работы реализованы функции для выполнения математических вычислений и написаны модульные тесты для проверки их корректности.

## 2. Функциональность

В файле `rectangle.py` реализованы две функции.

### 2.1. Функция area(a, b)

Функция вычисляет площадь прямоугольника по двум сторонам.

**Параметры:**
- `a` — длина первой стороны;
- `b` — длина второй стороны.

**Пример вызова:**

```python
area(5, 4)
```

**Результат:** `20`.

### 2.2. Функция perimeter(a, b)

Функция вычисляет периметр прямоугольника по двум сторонам.

**Параметры:**
- `a` — длина первой стороны;
- `b` — длина второй стороны.

**Пример вызова:**

```python
perimeter(5, 4)
```

**Результат:** `18`.

## 3. Технологии

- Python 3;
- библиотека `unittest` для модульного тестирования;
- Git для контроля версий;
- GitHub для хранения исходного кода проекта.

## 4. Unit-тестирование

Для проверки корректности работы функций создан файл `test_rectangle.py`.

Реализованы следующие тесты:

1. `test_zero_area` — проверка площади при нулевой длине одной из сторон.
2. `test_square_area` — проверка площади квадрата.
3. `test_rectangle_area` — проверка площади прямоугольника.
4. `test_zero_perimeter` — проверка периметра при нулевых значениях сторон.
5. `test_square_perimeter` — проверка периметра квадрата.
6. `test_rectangle_perimeter` — проверка периметра прямоугольника.

Для запуска тестов используется команда:

```powershell
& "C:\msys64\ucrt64\bin\python.exe" -m unittest -v test_rectangle
```

Все шесть тестов успешно пройдены.
