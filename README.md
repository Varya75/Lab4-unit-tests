# Лабораторная работа №4. Написание Unit-тестов

---

## Описание проекта

Данный проект выполнен в рамках лабораторной работы №4 по дисциплине **ИСРПО**.

Цель работы — изучение принципов модульного тестирования программного обеспечения с использованием стандартной библиотеки Python `unittest`.

## Функциональность программы

Программа предназначена для вычисления площади и периметра прямоугольника по заданным сторонам.

Реализованы следующие функции:

- `area(a, b)` — вычисление площади прямоугольника;
- `perimeter(a, b)` — вычисление периметра прямоугольника.

## Используемые технологии

- **Язык программирования:** Python 3.14.7
- **Библиотека тестирования:** unittest
- **Система контроля версий:** Git
- **Платформа размещения кода:** GitHub

## Модульное тестирование

Для проверки корректности работы программы разработаны Unit-тесты с использованием библиотеки `unittest`.

В процессе тестирования проверяются следующие случаи:

1. Вычисление площади при нулевой стороне.
2. Вычисление площади квадрата.
3. Вычисление площади прямоугольника.
4. Вычисление периметра при нулевых сторонах.
5. Вычисление периметра квадрата.
6. Вычисление периметра прямоугольника.

## Запуск тестов

Для запуска тестирования необходимо выполнить команду:

```bash
python -m unittest -v test_rectangle
```
